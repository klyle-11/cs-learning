Grid

Paste text or upload files containing HTTPS links and build a media grid. URLs are used as-is; switch to Convert URLs mode to rewrite them with transform rules first.

1. Paste text or upload files

URLs can be in ordinary text, Markdown, HTML, JSON, CSV, logs, or one URL per line. Only https:// links are extracted. JSON entries with a media URL and a post/page URL (e.g. mediaUrl + postUrl), and bookmark exports where a direct media link sits next to its site link, become one card with both links.

Drop JSON, bookmark .html, or text files anywhere on this panel. Add to grid (Ctrl+Enter) keeps each paste as a source and clears the box, so pastes and files keep adding to the same grid. Duplicates are skipped across all of them.

    Or add a whole local folder of images/videos. Files stay local to this browser tab; relative folder paths are kept as labels when the browser provides them.

    2. Transform rules

    Leave any field empty to preserve that part of the original URL. Rules run in the displayed order: domain, path prefix, slug, file extension, then query parameters.

    URLs on these domains (and their subdomains) skip the rules above and are replaced by the direct media URL yt-dlp returns; the original URL is kept as the page link. Needs the local helper running: python grid-ytdlp.py.
