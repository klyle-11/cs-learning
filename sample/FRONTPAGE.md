# CS Learning

A self-directed track through computer science fundamentals, taken one small step at a time.

- **C and systems**: lessons, data structures and the project ladder from a unix shell up to a tiny OS kernel, in `docs/` and `c-lessons-project/`.
- **Discrete maths and proofs**: how each idea is abstracted in programming, with C++ for the parallels, in `discrete-math/`.

Pick a document, read slowly, and write notes or questions in the box at the bottom as they come up. Select text first to pin a note to it.
