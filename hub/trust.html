Trust this hub

Checking how this page reached you…

The hub encrypts everything it sends. To do that it shows your device a certificate, and your device has never met the hub, so the browser warns you. You fix that once per device by installing the hub's own certificate authority: a small file that says "certificates signed by this hub are genuine".

It can vouch for this hub only: the hub's own names, and addresses on a home network. It cannot vouch for a website, and browsers enforce that. It is public, not a secret. The authority's own private key was used once, when it was made, and is not kept anywhere.

Replacing an older one? A hub set up before October 2026 used an authority called "Hub local authority", which had no such limit. If this device has it, remove it: on an iPhone or iPad, Settings → General → VPN & Device Management → "Hub local authority" → Remove Profile; on a Mac, Keychain Access → search for "Hub local authority" → delete it. Then install the new one below.

1. Check it is the right hub

The hub printed a fingerprint when it started (the board shows it on its screen). It must match this one:

…

Why this matters. Until the authority is installed, this page and the file below come over a connection that is not encrypted yet. Someone else on the same network could swap the file, and the fingerprint shown here, for their own; this device would then trust them, and they could read everything it sends to the hub. What they cannot change is what the hub itself printed. So compare with that, character for character, not with anything else this browser shows. If they differ, do not install it.

Without the network at all: copy the file from the hub's computer to this device directly (AirDrop, a cable, a USB stick) and install it from there. The hub printed where it is (ca.pem in its state folder); it is the same file as the download below.

3. Install it

iPhone and iPad
  1. Download it in Safari and allow the profile.
  2. Settings → General → VPN & Device Management → the "Hub authority (this hub only)" profile → Install.
  3. Settings → General → About → Certificate Trust Settings → switch on "Hub authority (this hub only)".
Android
  1. Settings → Security (or "Security & privacy") → More settings → Encryption & credentials → Install a certificate → CA certificate.
  2. Choose "Install anyway", then pick hub-ca.crt from Downloads.
Mac
  1. Open the downloaded file; Keychain Access adds it to the login keychain.
  2. In Keychain Access, double-click "Hub authority (this hub only)" → Trust → "When using this certificate": Always Trust.
  3. Firefox keeps its own list: Settings → Privacy & Security → Certificates → View Certificates → Authorities → Import.
Windows
  1. Open the downloaded file → Install Certificate → Current User.
  2. "Place all certificates in the following store" → Trusted Root Certification Authorities → Finish.
Linux
  1. Chrome: Settings → Privacy and security → Security → Manage certificates → Authorities → Import.
  2. Firefox: Settings → Privacy & Security → Certificates → View Certificates → Authorities → Import.

4. Open the reader

Open the reader over HTTPS

If it opens with no warning, this device trusts the hub and you are done. If the browser still warns, the authority is not installed yet (on iPhone, step 3's last line is the one most often missed); close and reopen the browser after installing.

Next the reader asks for a pairing code, which is a separate step: the certificate proves the hub to your device, the code proves your device to the hub.
