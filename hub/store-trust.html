The board made one self-signed certificate for this store. Your browser has never seen it, so the first connection shows a warning. Accept the warning for this address, or install the certificate below if you want this device to remember it permanently.

1. Check it is your board

Compare this SHA-256 fingerprint with the fingerprint printed on the board's serial console when it first made the certificate:

The browser did not trust this connection yet, so the value on this page is not proof by itself. The value printed by the board is the one to trust. Stop if they differ.

2. Remember the certificate (optional)

Download hub-store.crt

  1. Open the downloaded certificate and add it to this device's trusted certificates.
  2. On macOS, set this certificate to “Always Trust” in Keychain Access. On iPhone or iPad, also enable it under Certificate Trust Settings.
  3. Close and reopen the browser, then return to the board's .local address.

This is the board's server certificate, not a certificate authority. It can identify only this board, under the names recorded when the certificate was made.
